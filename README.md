# BOOTSTRAP | Premium Footwear Showcase

Welcome to **BOOTSTRAP**, a sophisticated and visually stunning footwear showcase web application. This project highlights a premium collection of footwear across various distinct categories with a modern, high-contrast user interface.

## 🌟 Live Demo
The project is live and deployed via GitHub Pages:
👉 **[View the Live Site Here!](https://sayanjana2005.github.io/shoe-showcase/)**

## ✨ Features
* **Modern Design**: High-contrast, dark-mode aesthetic with custom radial gradients, glassmorphism UI elements, and sleek modern typography.
* **Fully Responsive**: Optimized for all devices, including a custom off-canvas hamburger navigation menu for mobile devices.
* **Smooth Animations**: Integrated micro-interactions such as hover effects, scaling transitions, and smooth fade-ins across all pages.
* **Premium Collections**: Showcases five distinct product lines:
  * Signature Boots
  * Urban Sneakers
  * Athletic High-Tops
  * Resort & Summer
  * Lounge & Comfort
* **Dynamic Sorting**: Separate categories specifically tailored and easily toggleable between Men's and Women's collections.

## 🛠️ Built With
* **HTML5**: Semantic and structural layout.
* **CSS3**: Advanced styling, CSS variables, flexbox/grid layouts, and responsive media queries.
* **Vanilla JavaScript**: Navigation toggles, scroll animations, and layout filtering.

## 🚀 Getting Started

If you want to run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sayanJana2005/shoe-showcase.git
   ```
2. **Open the project directory:**
   ```bash
   cd shoe-showcase
   ```
3. **Launch the site:**
   Since this is a static website, you can simply open `index.html` in your favorite web browser. Alternatively, you can use a local development server like Live Server (for VS Code) or Python:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000` in your browser.
